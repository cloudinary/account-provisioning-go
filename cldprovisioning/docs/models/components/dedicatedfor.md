# DedicatedFor

Designates the access key for a specific purpose while allowing it to be used for other purposes, as well.
This action replaces any previously assigned key. **Possible values**: `webhooks`


## Example Usage

```go
import (
	"github.com/cloudinary/account-provisioning-go/cldprovisioning/models/components"
)

value := components.DedicatedForWebhooks
```


## Values

| Name                   | Value                  |
| ---------------------- | ---------------------- |
| `DedicatedForWebhooks` | webhooks               |

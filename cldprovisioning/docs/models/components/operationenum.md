# OperationEnum

Specifies the operation to perform. Use `add` to associate or `remove` to disassociate.

## Example Usage

```go
import (
	"github.com/cloudinary/account-provisioning-go/cldprovisioning/models/components"
)

value := components.OperationEnumAdd
```


## Values

| Name                  | Value                 |
| --------------------- | --------------------- |
| `OperationEnumAdd`    | add                   |
| `OperationEnumRemove` | remove                |

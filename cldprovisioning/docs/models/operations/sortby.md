# SortBy

Which response parameter to sort by. **Possible values**: `api_key`, `created_at`, `name`, `enabled`.


## Example Usage

```go
import (
	"github.com/cloudinary/account-provisioning-go/cldprovisioning/models/operations"
)

value := operations.SortByAPIKey
```


## Values

| Name              | Value             |
| ----------------- | ----------------- |
| `SortByAPIKey`    | api_key           |
| `SortByCreatedAt` | created_at        |
| `SortByName`      | name              |
| `SortByEnabled`   | enabled           |

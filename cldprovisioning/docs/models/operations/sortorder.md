# SortOrder

Control the order of returned keys. **Possible values**: `desc` (default), `asc`.


## Example Usage

```go
import (
	"github.com/cloudinary/account-provisioning-go/cldprovisioning/models/operations"
)

value := operations.SortOrderDesc
```


## Values

| Name            | Value           |
| --------------- | --------------- |
| `SortOrderDesc` | desc            |
| `SortOrderAsc`  | asc             |
